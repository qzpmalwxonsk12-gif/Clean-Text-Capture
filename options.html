Chapter copy settings

All timings are in seconds. Save applies changes to the running collection; no restart is needed.

Checks loading more frequently and opens the verified next chapter directly, without waiting for WTR's scroll-based Next button. It does not switch your active tab. Fast preset: 0.5s settling, 0s after-copy, 2s fallback. Presets save immediately and keep your security retry interval.

0.1–60. Requires unchanged text across this interval. Lower values are faster but can miss late-arriving text; loading, chapter-identity and security checks remain enabled.

0–60. Extra pacing for clipboard-watcher apps and the website, not a requirement of copying. Zero removes the extra wait. Very fast copies may be missed by CopyAPP; the extension's PDF backup is independent.

0–60. After a Next-button click fails to advance, wait this long before opening its verified chapter URL once. Fast navigation normally opens that URL immediately, so this timer only applies to button navigation. Never runs during a security check.

1–60. Nothing is copied or advanced during a security check. This timer is separate from normal chapter loading checks.

Background tabs may run more slowly because Chrome can delay timers. Security checks are never clicked automatically.
